# 매매 전략 리뷰 & v5.8 임계값 확정 (멀티 레짐 백테스트)

작성: 2026-06-05 · 자본금 500만원 기준 · `scripts/backtest-harness.mjs`

## 1. v5.7 진단 — 무엇이 망가졌나

2025 폭등장(KOSPI +190%) 1년 백테스트에서 v5.7 은 +73.6% 에 그쳤다. 거래 로그를
분해한 결과 원인이 명확했다.

| 매도 사유 | 건수 | 승률 | 평균수익 | 실현손익 |
|---|---|---|---|---|
| 트레일링 스톱 | 83 | 100% | +12.53% | **+5,766,712원** ✅ |
| KOSPI 스파이크 | 11 | 100% | +7.02% | +450,640원 ✅ |
| **순위 이탈** | 110 | **32%** | **−3.15%** | **−1,880,091원** ❌ |

- **순위 이탈 즉시매도(`현재순위 > 매수순위`)가 단독으로 188만원을 까먹음.**
- 전체 매도의 54%, **80% 가 매수 3일 이내**, 보유기간 중앙값 0일의 초단타 회전 유발.
- 시총 순위는 상대적·서수적 노이즈라 15→16위 흔들림에도 매번 손절.

## 3. 멀티 레짐 강건성 — 핵심 검증

| Config | 2025 상승(+190%) | 2022 하락(−25%) | 2020 폭락+회복(+32%) |
|---|---|---|---|
| C0 baseline | +73.6% | −27.6% | +34.5% |
| **C1 히스테리시스** | **+80.1%** | **−25.1%** | +31.7% |
| C10 통합 | +92.1% | −26.2% | +38.3% |
| C16 (비중 제외) | +64.6% ⚠️ | −23.8% | +30.1% |
| 하드 손절 −8% | +60.9% ❌ | −25.8% | +23.4% ❌ |

### 확정된 사실
1. ✅ **히스테리시스 순위 매도** — 3개 레짐 **전부** baseline 개선/동급. 거래 5~10배↓.
   가장 강건하고 메커니즘이 명확(노이즈 손절 제거). **→ v5.8 채택.**
2. ✅ **트레일링 −2% 유지** — 완화(C3/C12)하면 3개 레짐 모두 악화. 폭등장에선
   타이트 트레일링 + 재매수가 추세를 더 잘 포착. **→ 변경 없음.**
3. ✅ **하드 스톱로스 거부** — 메가캡 평균회귀를 역행. V자 반등(2020) 바닥에서 손절 →
   회복장 +38%→+23%. 휩쏘. **→ 미채택.**
4. ⚠️ **목표비중·z-score** — C10 에선 최고지만 C16 이상현상(비중 제외 시 baseline 이하)이
   **파라미터 간 비선형 상호작용 = 단일 상승장 과최적화 위험**을 드러냄.
   실거래 자금엔 추가 out-of-sample 검증 후 단계 적용. **→ v5.9 후보로 보류.**

## 4. v5.8 적용 내역

순위 이탈 매도를 **즉시 → 히스테리시스**로 전환:
- 모니터링 유니버스(**Top 20**) 밖으로 이탈 + **연속 2거래일** 확인돼야 매도.
- `buy_rank` 와 무관하게 "유니버스 이탈 확정"만 판단 → 사용자 의도("10위권 밖이라고
  성급히 팔지 않기")와 정확히 일치.
- 이익 +10% 도달(trailingActive) 종목은 트레일링이 우선 관리 → 승자 조기청산 방지.
- **거래일 단위 카운팅**: 운영 cron 이 시간당(하루 6회) 돌아도 하루 1회만 카운트 증가 →
  백테스트(일봉 2일)와 동일 민감도 유지. `position_tracking.out_of_universe_count`/`last_out_date`.

상수 (`rebalanceStrategy.ts`):
```
EXIT_RANK_THRESHOLD = 20   // Top 20 밖 이탈 기준
EXIT_CONFIRM_TICKS  = 2    // 연속 2거래일 확인
TRAILING_STOP_DROP_PCT = 2 // 유지 (백테스트상 완화 시 악화)
```

## 5. 방법론 한계 (정직성)

- **단일 레짐 과최적화 위험**: 각 연도는 1개 실현경로일 뿐. C16 이상현상이 보여주듯
  파라미터 조합 민감도가 큼 → 보수적으로 강건한 변경(히스테리시스)만 채택.
- **합성 순위**: 실제 시총순위 이력이 아닌 종가×현재발행주수 추정. A/B 비교는 동일
  근사를 양쪽에 적용하므로 "파라미터 효과" 비교는 유효, 절대 순위는 ±오차.
- **생존편향**: 종목 풀 25개가 현재 대형주 → 절대수익 과대평가. 2020/2022 는 일부
  종목 미상장(LG엔솔 2022·HD현대중공업 2024)으로 23~25종목.
- **슬리피지 0**: 545회 거래 비용 무시 → 회전 많을수록 실거래는 더 나쁨. 즉 회전을
  5~10배 줄이는 히스테리시스의 실거래 이점은 백테스트보다 **더 크다**.

## 6. 다음 단계 (v5.9 후보)

- 목표비중 사이징(8종목 균등 + ±20% 무거래밴드)을 **out-of-sample**(2021·2023·2024)에서
  재검증 후 단계 적용. C10 의 +18.5%p 초과수익 대부분이 여기서 나옴.
- 베어장 방어: 모든 config 가 2022 에 ~−25% 손실. 인덱스 추종형 long-only 의 구조적 한계.
  KOSPI 200일선 하회 시 현금 비중 확대(마켓타이밍 오버레이)는 휩쏘 위험 있어 별도 검증 필요.
